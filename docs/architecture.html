Runtime path — one frame

Every frame walks the same seven stops. The proposer is deliberately over-eager and the verifier is what makes the output trustworthy; nothing is ever reported from a single frame.

Why a second stage exists at all. Set YOLOv8n low enough to catch a prone, half-buried, badly lit survivor and it also returns debris, mannequin limbs and motion blur. Set it high enough to reject those and it misses people. So the proposer stays at high recall and the SSN decides what was real, using the one signal a single frame cannot carry: a survivor is present in every frame, an artefact is not.

Dependency layers

Two modules import nothing from the package. Everything else stacks on them, which is what makes model.py and localize.py independently testable — and why the geometry can be verified without a network and the network without a camera.

Why the verifier spikes

The LIF membrane is the whole architectural bet, and it is small enough to trace by hand. Below is the real membrane potential from ssn.model.LIF at its initialised decay of 0.5, driven two ways at identical amplitude.

Training path

Labels come from a teacher-student split: the same low-confidence proposer that will fly decides what gets looked at, and a heavier YOLOv8l decides what was really there. Training on the student's own candidate distribution is the point — a set of tidy person crops would teach nothing about the debris it must reject.

Accuracy is the wrong score here. Harvested windows are mostly negatives, so answering “no survivor” to everything scores well and is worthless. The reported number is false positives removed at matched recall: fix the threshold where the network still keeps 98% of real survivors, then count how many of the proposer's false positives it dropped. Gate B asks for ≥ 30%.

Recall is held near 1.0 rather than traded off. A missed survivor in a collapsed building is not a metric.

Module by module

Line numbers are against tag v2. Every module ends in a _demo() that asserts the behaviour it depends on — those are the tests, and they live next to the code they constrain rather than in a parallel tree.

model.py

leaf · no internal imports

The spiking verifier itself, and the two constants everything else agrees on.

Defines the network that votes on a candidate. Convolution and BatchNorm are folded into a single call over T×B and only the neuron state loops over time — that fusion is the difference between usable and unusable inference on ARM.

perception.py

core · imports model

Turns raw frames into verified candidates: warp, propose, track, crop, vote.

The runtime core. Pipeline.step is the per-frame entry point and is where the single ego-motion warp, the single proposer call and the one batched verification happen in that order.

localize.py

leaf · no internal imports

Pure geometry: pixel to floor point to grid cell, then deduplication.

A single camera cannot give depth, but survivors are on the floor — and that one fact supplies the missing constraint. The pixel gives a ray; the plane z = 0 gives where it lands. World frame is x east, y north, z up, origin at the arena corner.

train.py

imports model, data

The optimisation loop, and the metric the mission is actually judged on.

Scores the network the way Gate B does. The threshold is swept over observed scores rather than fixed at 0.5, because an untrained network's outputs sit in a narrow band and a fixed cut would report nonsense.

bench.py

run.py

imports model, perception, localize

The mission: video in, survivor grid events out as JSON.

The only module that touches all three others. Mission.step is where perception meets geometry — it takes verified tracks, projects the bottom edge of each box (floor contact, not the centre, which would put a standing person half a body too far) and merges the result into the registry.

SymbolRoleLine

run(source, out_path, max_frames, mission, show)Capture loop over a file or webcam index; releases the capture and swallows the headless destroyAllWindows failure in finally.86
mainCLI. Warns on stderr when no --weights is given rather than quietly emitting confident nonsense.126

Pose is injected, not solved. There is no SLAM in this package. build(pose_at=…) takes the live pose stream from FC telemetry or VIO; the default fixed hover pose is a stand-in for bench footage only. Real flight video through the default produces confident, wrong geotags.

The layer boundary is here. Mission.step emits one record per verified detection — time, track, box, confidence, floor position, grid cell, and the pose it was tagged with — and stops. Each record stands alone, so the mapping layer can associate them against its own trajectory without inheriting a decision this layer had no business making.

Entry points

Four CLIs, in the order you would use them.

python -m ssn.data flight.mp4 --out dataset Harvest labelled windows from footage.
python -m ssn.train --data dataset --epochs 40 Train, scored on FP removed at matched recall.
python -m ssn.bench --proposer Latency on the hardware you will actually fly.
python -m ssn.run flight.mp4 --weights ssn.pt Run the mission, write survivors.json.
python tests/test_ssn.py All seven module self-checks, about 15 seconds.
